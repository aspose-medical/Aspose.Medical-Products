<p><strong>Aspose.Medical for .NET</strong> egy tiszta .NET osztálykönyvtár DICOM (Digital Imaging and Communications in Medicine) fájlokkal való munkához. Lehetővé teszi a fejlesztők számára a DICOM orvosi képadatok olvasását, írását, módosítását, anonimizálását, átkódolását és megjelenítését, sorosítását DICOM JSON és DICOM XML formátumba, valamint a tanulmányok cseréjét más rendszerekkel DIMSE és DICOMweb protokollon keresztül, külső szoftver vagy natív függőség nélkül.</p>

<p>A könyvtár teljes egészében menedzselt C#-ban íródott, és .NET 10-en fut Windows, Linux és macOS rendszereken. Nincsenek natív binárisok és nincs harmadik féltől származó NuGet csomag, így a könyvtár egyetlen assembly-ként telepíthető bármely .NET alkalmazásba, legyen az asztali eszköz vagy felhőalapú egészségügyi rendszer konténer.</p>

<p><strong>Főbb funkciók:</strong>
<ul>
    <li>DICOM fájlok olvasása és írása fájlból, adatfolyamból vagy csőből, szinkron vagy aszinkron módon, teljes támogatással minden szabványos adat elemhez és érték reprezentációhoz.</li>
    <li>Memóriakezelés nagy fájlok esetén: minden elemet beolvas, a nagy elemeket elhalasztja amíg szükséges, vagy kihagyja őket és csak a metaadatot olvassa be.</li>
    <li>Bármely adat elem olvasása és szerkesztése, beleértve a sorozatokat és privát címkéket, nem ASCII szövegek karakterkódolásának kezelésével.</li>
    <li>DICOM fájlok anonimizálása a DICOM PS 3.15 titoktartási profiljaival, lehetőséggel az UID-ek, dátumok, eszköz- és intézményazonosítók és páciensjellemzők megtartására.</li>
    <li>Átkódolás a különböző átvitel szintaxisok között: JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL és RLE, minden codec .NET-ben megvalósítva.</li>
    <li>Képkockák renderelése BGRA pixelekre a modalitás LUT, a VOI LUT (ablak és szint) és az ábrázoló átfedésekkel.</li>
    <li>Adathalmazok sorosítása a DICOM JSON Modellbe (PS3.18) és DICOM XML-be (PS3.19), valamint vissza, aszinkron adatfolyamot és plug-in alapú tömeges adat betöltést is tartalmazva.</li>
    <li>Kommunikáció DIMSE-n keresztül kliens és szerver esetén: C-ECHO, C-STORE, C-FIND, C-MOVE, C-GET, az N-szolgáltatások és TLS.</li>
    <li>Modalitás worklist lekérdezése, MPPS jelentés és munka kiadása UPS-RS munkák segítségével, kliensként és szerverként.</li>
    <li>Tanulmányok keresése, letöltése és feltöltése bármely DICOMweb szerveren, típusos klienssel QIDO-RS, WADO-RS, STOW-RS, renderelt képek, WADO-URI és munkafolyamat szolgáltatások támogatásával.</li>
    <li>Saját DICOMweb szerver építése: QIDO-RS, WADO-RS, STOW-RS és a munkafolyamat szolgáltatások ASP.NET Core vagy bármely más HTTP hoston, a tárolóval a háttérben.</li>
</ul>
</p>

<p>Aspose.Medical for .NET önálló. Nem igényel DICOM nézőt, orvosi képfeldolgozó szoftvert és nem kell natív kodekeket telepíteni. Alkalmas egészségügyi IT rendszerekhez, PACS integrációhoz, telemedicina platformokhoz és bármely olyan alkalmazáshoz, amely megbízhatóan kell, hogy feldolgozza a DICOM adatokat.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     Tiszta .NET könyvtár – nulla függőség
    </h2>
    <p>
     Az Aspose.Medical for .NET teljes egészében menedzselt C#-ban íródott, és egyetlen assembly-ként szállítja, natív binárisok és harmadik féltől származó NuGet csomagok nélkül. Más orvosi képfeldolgozó könyvtárak natív kodekekre vagy külső eszközökre támaszkodnak; ez nem így van. Minden kép tömörítő kodek (JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL, RLE) .NET-ben valósult meg, így a könyvtár Windows, Linux és macOS alatt ugyanúgy viselkedik. Ezért ideális konténerekhez, felhő környezetekhez és bármely telepítéshez, ahol a natív könyvtárak telepítése nem opció. A csomag .NET 10-re céloz.

   <div class="col-lg-12">
    <h2 class="h2title">
     DICOM fájlok anonimizálása az adatvédelmi megfelelőség érdekében
    </h2>
    <p>
     A páciens adatvédelem szigorú követelmény az egészségügyi alkalmazásokban. Az Aspose.Medical for .NET a DICOM PS 3.15 titoktartási profiljaival anonimizálja a DICOM adatokat. Eltávolíthatja vagy helyettesítheti a páciens azonosító információkat, miközben megőrzi a képadatok klinikai értékét, és kiválaszthatja, hogy egy profil milyen adatokat tartson meg: biztonságos privát attribútumok, UID-ek, eszköz- és intézményazonosítók, páciensjellemzők és longitudinális időbeli információk. A <a href="/medical/net/anonymization/">DICOM anonimizálási oldal</a> részletesen bemutatja a profilbeállításokat.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM fájl anonimizálása – C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     DICOM képkockák renderelése .NET C#-ban
    </h2>
    <p>
     Az Aspose.Medical for .NET egy DICOM képkockát 32-bites BGRA pixelképpé renderel. A renderelő alkalmazza a fotometrikus interpretációt, a modalitás LUT-ot és a VOI LUT-ot (ablak és szint) az adathalmazból, és megrajzolja az átfedéseket, így az eredmény megfelel egy néző által mutatott képnek. A pixelek ezután az önéi: másolja őket egy pufferbe, és adja át bármely képkönyvtárnak PNG, JPEG vagy TIFF mentéséhez. Az egyetlen beépített képkódoló a könyvtárban a PNM. A konverziós oldalak bemutatják a teljes útvonalat a <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a> és <a href="/medical/net/dicom-to-tiff/">TIFF</a> esetén.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM képkocka renderelése – C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Átkódolás a transfer szintaxisok között
    </h2>
    <p>
     Képrendszer- és archívumok specifikus DICOM transfer szintaxisokat igényelnek. Az Aspose.Medical for .NET átkódol az el nem tömörített formátumok, JPEG Baseline, JPEG Extended, JPEG Lossless, JPEG-LS, JPEG 2000, HTJ2K (High-Throughput JPEG 2000), JPEG XL és RLE között. A HTJ2K és a JPEG XL a DICOM szabvány legújabb két opciója, és itt .NET-ben vannak megvalósítva, mint minden más kodek. Az átkódolás fontos a PACS integrációhoz, az archívum méretéhez és a rendszerek közti kompatibilitáshoz. Tekintse meg a <a href="/medical/net/dicom-transfer-syntax-conversion/">transfer szintaxis konverziós oldalt</a> és a <a href="/medical/net/jpeg2000/">JPEG 2000 oldalt</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM átkódolása HTJ2K formátumba – C#
     </h3>
     <pre><code class="cs">// Load existing DICOM file
DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to High-Throughput JPEG 2000, lossless
DicomFile transcoded = dicomFile.Transcode(TransferSyntax.HTJ2KLossless);

// Save the transcoded file
transcoded.Save("output.dcm");</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     DICOM sorosítása JSON és XML formátumba
    </h2>
    <p>
     Az egészségügyi rendszerek webszolgáltatásokon keresztül cserélnek adatokat, ezért az Aspose.Medical for .NET sorosítja a DICOM adathalmazokat a DICOM JSON Modellbe (PS3.18) és a DICOM XML-be (PS3.19), valamint visszaelemzi őket adathalmazokká. A sorosítók karakterláncokon, adatfolyamokon és csöveken működnek, szinkron és aszinkron módon, és a adathalmazok sorozata egyenként olvasható anélkül, hogy a teljes dokumentumot memóriában tartaná. A tömeges adat hivatkozásokat egy plug-in betöltővel oldja fel, így a nagy képpont adatok a dokumentumon kívül maradhatnak. Lásd a <a href="/medical/net/dicom-to-json/">DICOM → JSON</a> és a <a href="/medical/net/dicom-to-xml/">DICOM → XML</a> oldalakat.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM sorosítása JSON és XML formátumba – C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");
Dataset dataset = dicomFile.Dataset;

// Serialize the dataset to JSON (DICOM JSON Model) and to DICOM XML
string json = DicomJsonSerializer.Serialize(dataset, writeIndented: true);
string xml = DicomXmlSerializer.Serialize(dataset);
