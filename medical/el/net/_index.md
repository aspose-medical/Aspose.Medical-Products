<p><strong>Aspose.Medical for .NET</strong> είναι μια καθαρή .NET βιβλιοθήκη κλάσεων για εργασία με αρχεία DICOM (Digital Imaging and Communications in Medicine). Επιτρέπει στους προγραμματιστές να διαβάζουν, γράφουν, τροποποιούν, ανωνυμοποιούν, μετακωδικοποιούν και αποδίδουν δεδομένα ιατρικής απεικόνισης, να τα σειριοποιούν σε DICOM JSON και DICOM XML, και να ανταλλάσσουν μελέτες με άλλα συστήματα μέσω DIMSE και DICOMweb, χωρίς κανένα εξωτερικό λογισμικό ή ντόπιες εξαρτήσεις.</p>

<p>Η βιβλιοθήκη είναι γραμμένη εξ ολοκλήρου σε διαχειριζόμενο C# και τρέχει σε .NET 10 στα Windows, Linux και macOS. Δεν υπάρχουν ντόπια εκτελέσιμα και δεν χρησιμοποιούνται πακέτα NuGet τρίτων, επομένως η βιβλιοθήκη αναπτύσσεται ως ένα ενιαίο assembly σε οποιαδήποτε .NET εφαρμογή, από εργαλείο επιφάνειας εργασίας μέχρι κοντέινερ σε cloud σύστημα υγειονομικής περίθαλψης.</p>

<p><strong>Βασικά Χαρακτηριστικά:</strong>
<ul>
    <li>Ανάγνωση και εγγραφή αρχείων DICOM από αρχείο, ροή ή pipe, συγχρονισμένα ή ασύγχρονα, με πλήρη υποστήριξη για όλα τα τυπικά στοιχεία δεδομένων και αναπαραστάσεις τιμών.</li>
    <li>Έλεγχος μνήμης σε μεγάλα αρχεία: φόρτωση κάθε στοιχείου, καθυστέρηση μεγάλων στοιχείων μέχρι να χρησιμοποιηθούν, ή παράλειψή τους και ανάγνωση μόνο των μεταδεδομένων.</li>
    <li>Ανάγνωση και επεξεργασία οποιουδήποτε στοιχείου δεδομένων, συμπεριλαμβανομένων ακολουθιών και ιδιωτικών ετικετών, με διαχείριση συνόλου χαρακτήρων για κείμενο μη‑ASCII.</li>
    <li>Ανωνυμοποίηση αρχείων DICOM με τις προφίλ εμπιστευτικότητας του DICOM PS 3.15, με επιλογές διατήρησης UID, ημερομηνιών, ταυτοτήτων συσκευής και ιδρύματος, και χαρακτηριστικών ασθενή.</li>
    <li>Μετακωδικοποίηση μεταξύ συντακτικών μεταφοράς: JPEG, JPEG‑LS, JPEG 2000, HTJ2K, JPEG XL και RLE, με όλα τα codecs να υλοποιούνται σε .NET.</li>
    <li>Απόδοση πλαισίων σε pixels BGRA με το LUT λειτουργίας, το VOI LUT (παράθυρο και επίπεδο) και επικάλυψη που εφαρμόζει ο renderer.</li>
    <li>Σειριοποίηση συνόλων δεδομένων στο μοντέλο DICOM JSON (PS3.18) και σε DICOM XML (PS3.19) και αντίστροφα, συμπεριλαμβανομένης της ασύγχρονης μετάδοσης και της προσθετικής φόρτωσης bulk δεδομένων.</li>
    <li>Επικοινωνία μέσω DIMSE με πελάτη και διακομιστή: C‑ECHO, C‑STORE, C‑FIND, C‑MOVE, C‑GET, οι N‑services και TLS.</li>
    <li>Αναζήτηση, λήψη και αποστολή μελετών σε οποιονδήποτε διακομιστή DICOMweb με typed client για QIDO‑RS, WADO‑RS, STOW‑RS, αποδιδόμενες εικόνες, WADO‑URI και τις υπηρεσίες ροής εργασίας.</li>
    <li>Δημιουργία του δικού σας διακομιστή DICOMweb: QIDO‑RS, WADO‑RS, STOW‑RS και οι υπηρεσίες ροής εργασίας σε ASP.NET Core ή οποιονδήποτε άλλο HTTP host, με την αποθήκευσή σας πίσω από αυτά.</li>
</ul>

Άλλες βιβλιοθήκες ιατρικής απεικόνισης εξαρτώνται από ντόπια codecs ή εξωτερικά εργαλεία· αυτή όχι. Όλα τα codecs συμπίεσης εικόνας (JPEG, JPEG‑LS, JPEG 2000, HTJ2K, JPEG XL, RLE) υλοποιούνται σε .NET, έτσι η βιβλιοθήκη συμπεριφέρεται όμοια σε Windows, Linux και macOS. Αυτό την καθιστά ιδανική για containers, cloud περιβάλλοντα και κάθε ανάπτυξη όπου η εγκατάσταση ντόπιων βιβλιοθηκών δεν είναι επιλογή. Το πακέτο στοχεύει .NET 10.

   <div class="col-lg-12">
    <h2 class="h2title">
     Ανωνυμοποίηση Αρχείων DICOM για Συμμόρφωση με Ιδιωτικότητα
    </h2>
    <p>
     Η ιδιωτικότητα του ασθενούς αποτελεί αυστηρή απαίτηση σε εφαρμογές υγειονομικής περίθαλψης. Το Aspose.Medical for .NET ανωνυμοποιεί δεδομένα DICOM με τα προφίλ εμπιστευτικότητας του DICOM PS 3.15. Μπορείτε να αφαιρέσετε ή να αντικαταστήσετε τις ταυτοποιητικές πληροφορίες του ασθενούς διατηρώντας την κλινική αξία των δεδομένων απεικόνισης, και να επιλέξετε τι διατηρεί ένα προφίλ: ασφαλή ιδιωτικά χαρακτηριστικά, UID, ταυτοποίηση συσκευής και ιδρύματος, χαρακτηριστικά ασθενή, και χρονικές πληροφορίες. Η <a href="/medical/net/anonymization/">σελίδα ανωνυμοποίησης DICOM</a> παρουσιάζει λεπτομερώς τις επιλογές προφίλ.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Ανωνυμοποίηση αρχείου DICOM – C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Απόδοση Καρέ DICOM σε .NET C#
    </h2>
    <p>
     Το Aspose.Medical for .NET αποδίδει ένα καρέ DICOM σε εικόνα pixel 32‑bit BGRA. Ο renderer εφαρμόζει την φωτομετρική ερμηνεία, το modality LUT και το VOI LUT (παράθυρο και επίπεδο) από το σύνολο δεδομένων και σχεδιάζει τις επικάλυψεις, ώστε το αποτέλεσμα να αντιστοιχεί σε αυτό που δείχνει ένας προβολέας. Τα pixels είναι στη διάθεσή σας: αντιγράψτε τα σε buffer και περάστε τα σε οποιαδήποτε βιβλιοθήκη απεικόνισης για αποθήκευση ως PNG, JPEG ή TIFF. Ο μόνος ενσωματωμένος κωδικοποιητής εικόνας είναι το PNM. Οι σελίδες μετατροπής δείχνουν τη πλήρη διαδρομή για <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a> και <a href="/medical/net/dicom-to-tiff/">TIFF</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Απόδοση ενός καρέ DICOM – C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>
    </div>

    <h2 class="h2title">
     Μετακωδικοποίηση μεταξύ Συντακτικών Μεταφοράς
    </h2>
    <p>
     Τα συστήματα απεικόνισης και τα αρχεία απαιτούν συγκεκριμένα συντακτικά μεταφοράς DICOM. Το Aspose.Medical for .NET μετακωδικοποιεί μεταξύ μη‑συμπιεσμένων μορφών, JPEG Baseline, JPEG Lossless, JPEG‑LS, JPEG 2000, HTJ2K (High‑Throughput JPEG 2000), JPEG XL και RLE.
