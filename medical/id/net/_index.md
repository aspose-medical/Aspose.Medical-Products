<p><strong>Aspose.Medical for .NET</strong> adalah perpustakaan kelas .NET murni untuk bekerja dengan file DICOM (Digital Imaging and Communications in Medicine). Ini memungkinkan pengembang membaca, menulis, memodifikasi, menganonimkan, mentranskode, dan merender data pencitraan medis, menserialisasikannya ke DICOM JSON dan DICOM XML, serta menukar studi dengan sistem lain melalui DIMSE, tanpa perangkat lunak eksternal atau dependensi native.</p>

<p>Perpustakaan ini ditulis sepenuhnya dalam C# yang dikelola dan berjalan pada .NET 10 di Windows, Linux, dan macOS. Tidak ada binari native dan tidak ada paket NuGet pihak ketiga, sehingga perpustakaan dapat dideploy sebagai satu assembly ke aplikasi .NET apa pun, mulai dari alat desktop hingga kontainer dalam sistem perawatan kesehatan berbasis cloud.</p>

<p><strong>Fitur Utama:</strong>
<ul>
    <li>Membaca dan menulis file DICOM dari file, aliran, atau pipa, secara sinkron atau asinkron, dengan dukungan penuh untuk semua elemen data standar dan representasi nilai.</li>
    <li>Mengontrol memori pada file besar: memuat setiap elemen, menunda elemen besar sampai dipakai, atau melewatkannya dan hanya membaca metadata.</li>
    <li>Membaca dan mengedit elemen data apa pun, termasuk urutan dan tag privat, dengan penanganan set karakter untuk teks non-ASCII.</li>
    <li>Menganonimkan file DICOM dengan profil kerahasiaan DICOM PS 3.15, dengan opsi mempertahankan UID, tanggal, pengenal perangkat dan institusi, serta karakteristik pasien.</li>
    <li>Mentranskode antar sintaks transfer: JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL, dan RLE, dengan setiap codec diimplementasikan dalam .NET.</li>
    <li>Merender frame ke piksel BGRA dengan LUT modality, LUT VOI (window dan level) serta overlay yang diterapkan oleh renderer.</li>
    <li>Menyerialisasikan dataset ke Model DICOM JSON (PS3.18) dan ke DICOM XML (PS3.19) serta kembali, termasuk streaming asinkron dan pemuatan data bulk yang dapat dipasang.</li>
    <li>Berkomunikasi melalui DIMSE dengan klien dan server: C-ECHO, C-STORE, C-FIND, C-MOVE, C-GET, layanan N, dan TLS.</li>
</ul>
</p>

<p>Aspose.Medical for .NET adalah mandiri. Tidak memerlukan viewer DICOM, perangkat lunak pencitraan medis, atau codec native yang harus diinstal. Cocok untuk sistem TI perawatan kesehatan, integrasi PACS, platform telemedis, dan aplikasi apa pun yang harus memproses data DICOM secara andal.</p>

    <h2 class="h2title">
     Perpustakaan .NET Murni - Tanpa Dependensi
    </h2>
    <p>
     Aspose.Medical for .NET ditulis sepenuhnya dalam C# yang dikelola dan dikirim sebagai satu assembly tanpa binari native dan tanpa paket NuGet pihak ketiga. Perpustakaan pencitraan medis lain mengandalkan codec native atau alat eksternal; yang ini tidak. Semua codec kompresi gambar (JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL, RLE) diimplementasikan dalam .NET, sehingga perilakunya sama di Windows, Linux, dan macOS. Ini membuatnya cocok untuk kontainer, lingkungan cloud, dan deployment apa pun di mana pemasangan library native bukan pilihan. Paket ini menargetkan .NET 10.

    <h2 class="h2title">
     Anonimisasi File DICOM untuk Kepatuhan Privasi
    </h2>
    <p>
     Privasi pasien adalah keharusan dalam aplikasi perawatan kesehatan. Aspose.Medical for .NET menganonimkan data DICOM dengan profil kerahasiaan DICOM PS 3.15. Anda dapat menghapus atau mengganti informasi identitas pasien sambil mempertahankan nilai klinis data pencitraan, dan dapat memilih apa yang dipertahankan profil: atribut privat aman, UID, pengenal perangkat dan institusi, karakteristik pasien, serta informasi temporal longitudinal. <a href="/medical/net/anonymization/">Halaman anonimisasi DICOM</a> menampilkan opsi profil secara detail.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Anonimkan file DICOM - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Render DICOM Frames in .NET C#
    </h2>
    <p>
     Aspose.Medical for .NET merender sebuah frame DICOM menjadi gambar piksel BGRA 32-bit. Renderer menerapkan interpretasi fotometrik, LUT modality, dan LUT VOI (window dan level) dari dataset serta menggambar overlay, sehingga hasilnya cocok dengan apa yang ditampilkan viewer. Piksel tersebut kemudian menjadi milik Anda: salin ke buffer dan beri ke perpustakaan pencitraan apa pun untuk menyimpan PNG, JPEG, atau TIFF. Encoder gambar satu-satunya yang dibangun dalam perpustakaan adalah PNM. Halaman konversi menampilkan jalur lengkap untuk <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a>, dan <a href="/medical/net/dicom-to-tiff/">TIFF</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Render frame DICOM - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>

    <h2 class="h2title">
     Transkode Antar Sintaks Transfer
    </h2>
    <p>
     Sistem pencitraan dan arsip memerlukan sintaks transfer DICOM tertentu. Aspose.Medical for .NET mentranskode antara format tidak terkompresi, JPEG Baseline, JPEG Lossless, JPEG-LS, JPEG 2000, HTJ2K (High-Throughput JPEG 2000), JPEG XL, dan RLE. HTJ2K dan JPEG XL adalah dua opsi terbaru dalam standar DICOM, dan di sini keduanya diimplementasikan dalam .NET seperti semua codec lainnya. Transcoding penting untuk integrasi PACS, ukuran arsip, dan kompatibilitas antar sistem. Lihat <a href="/medical/net/dicom-transfer-syntax-conversion/">halaman konversi sintaks transfer</a> dan <a href="/medical/net/jpeg2000/">halaman JPEG 2000</a>.

      Transkode DICOM ke HTJ2K - C#
     </h3>
     <pre><code class="cs">// Load existing DICOM file
DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to High-Throughput JPEG 2000, lossless
DicomFile transcoded = dicomFile.Transcode(TransferSyntax.HTJ2KLossless);

// Save the transcoded file
transcoded.Save("output.dcm");</code></pre>

    <h2 class="h2title">
     Serialisasi DICOM ke JSON dan XML
    </h2>
    <p>
     Sistem perawatan kesehatan menukar data melalui layanan web, sehingga Aspose.Medical for .NET menyerialisasikan dataset DICOM ke Model DICOM JSON (PS3.18) dan ke DICOM XML (PS3.19), serta mengurai keduanya kembali menjadi dataset. Serializer bekerja pada string, aliran, dan pipa, sinkron maupun asinkron, dan urutan dataset dapat dibaca satu per satu tanpa menahan seluruh dokumen dalam memori. Referensi data bulk diselesaikan melalui loader yang dapat dipasang, sehingga data piksel besar dapat tetap berada di luar dokumen. Lihat halaman <a href="/medical/net/dicom-to-json/">DICOM ke JSON</a> dan <a href="/medical/net/dicom-to-xml/">DICOM ke XML</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Serialisasikan DICOM ke JSON dan XML - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");
Dataset dataset = dicomFile.Dataset;

// Serialize the dataset to JSON (DICOM JSON Model) and to DICOM XML
string json = DicomJsonSerializer.Serialize(dataset, writeIndented: true);
string xml = DicomXmlSerializer.Serialize(dataset);

// Parse both back into datasets
Dataset? fromJson = DicomJsonSerializer.Deserialize(json);
Dataset fromXml = DicomXmlSerializer.Deserialize(xml);</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     Jaringan DICOM melalui DIMSE
    </h2>
    <p>
     Aspose.Medical for .NET berkomunikasi langsung dengan sistem DICOM lain. Perpustakaan menyediakan klien DIMSE dan server DIMSE untuk C-ECHO, C-STORE, C-FIND, C-MOVE, dan C-GET, bersama layanan N, negosiasi asosiasi dengan konteks presentasi dan peran, jendela operasi asinkron, negosiasi identitas pengguna, serta TLS. Permintaan diantrekan pada asosiasi dan dijawab oleh handler yang Anda daftarkan, sehingga node store-and-forward, proxy query, atau test SCP menjadi hanya beberapa kelas. <a href="https://docs.aspose.com/medical/net/developer-guide/dicom-networking/">Panduan jaringan DICOM</a> mencakup seluruh API.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Kirim studi ke PACS dengan C-STORE - C#
     </h3>
     <pre><code class="cs">DicomFile dicomFile = DicomFile.Open("study.dcm");

DicomNetworkClient client = DicomNetworkClient
    .CreateBuilder(new DicomNetworkClientOptions
    {
        Called = "PACS_AE",
        Calling = "CLIENT_AE",
        Connection = new DicomNetworkConnectionOptions
        {
            TargetHost = new IPEndPoint(IPAddress.Parse("192.0.2.10"), 104)
        },
        AssociationNegotiation = new AssociationNegotiationOptions()
            .WithPresentationContext(new PresentationContext
            {
                AbstractSyntax = Uid.CTImageStorage,
                Role = null,
                TransferSyntaxes = ImmutableArray.Create(TransferSyntax.ExplicitVrLittleEndian)
            })
    })
    .Build();

client.QueueRequest(new CStoreRequest(dicomFile.Dataset, TransferSyntax.ExplicitVrLittleEndian));

await client.SendAsync(CancellationToken.None);
await client.StopAsync();</code></pre>

   <div class="col-lg-12">
    <h2 class="h2title">
     File DICOM Besar Tanpa Memori Besar
    </h2>
    <p>
     Whole slide images, long series and multi-frame studies do not fit comfortably in memory. Aspose.Medical for .NET lets you decide how much of a file is loaded: read everything, defer elements above a size threshold until they are accessed, or skip them and work with the metadata alone. Reading from a stream or a pipe and writing back the same way keeps the data moving instead of accumulating. The <a href="https://docs.aspose.com/medical/net/developer-guide/open-dicom-file/memory-management/">memory management guide</a> explains the trade-offs.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Baca metadata tanpa data piksel - C#
     </h3>
     <pre><code class="cs">// Elements larger than the threshold are not loaded into memory
DicomFile metadataOnly = DicomFile.Open(
    "whole_slide.dcm",
    ReadDicomFileOptions.Default,
    TagDataReadingStrategies.SkipLargeTags());

string? patientName = metadataOnly.Dataset.GetSingleValueOrDefault(Tag.PatientName, string.Empty);</code></pre>
