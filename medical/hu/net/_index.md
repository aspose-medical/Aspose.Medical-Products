<p><strong>Aspose.Medical for .NET</strong> egy tiszta .NET osztálykönyvtár DICOM (Digital Imaging and Communications in Medicine) fájlok kezelésére. Lehetővé teszi a fejlesztők számára a DICOM orvosi képalkotási adatok olvasását, írását, módosítását, anonimizálását, átkonvertálását és megjelenítését, sorosítását DICOM JSON és DICOM XML formátumba, valamint tanulmányok cseréjét más rendszerekkel DIMSE-n keresztül, külső szoftver vagy natív függőségek nélkül.</p>

<p>A könyvtár teljes egészében menedzselt C#-ban íródott, és .NET 10-en fut Windows, Linux és macOS rendszereken. Nincsenek natív binárisok és harmadik féltől származó NuGet csomagok, így a könyvtár egyetlen assembly-ként telepíthető bármely .NET alkalmazásba, legyen az asztali eszköz vagy felhőalapú egészségügyi rendszer konténer.</p>

<p><strong>Főbb jellemzők:</strong>
<ul>
    <li>DICOM fájlok olvasása és írása fájlból, stream-ből vagy pipe-ból, szinkron vagy aszinkron módon, teljes támogatással minden szabványos adat elem és érték reprezentáció esetén.</li>
    <li>Memóriakezelés nagy fájlok esetén: minden elemet betölteni, a nagy elemeket halasztani addig, amíg szükség van rájuk, vagy kihagyni őket és csak a metaadatot olvasni.</li>
    <li>Bármely adat elem olvasása és szerkesztése, beleértve a szekvenciákat és privát tageket, nem ASCII szövegek karakterkészletének kezelése.</li>
    <li>DICOM fájlok anonimizálása a DICOM PS 3.15 titoktartási profiljaival, lehetőségekkel az UID-k, dátumok, eszköz- és intézményazonosítók és a betegjellemzők megőrzésére.</li>
    <li>Átkonvertálás a transfer szintaxisok között: JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL és RLE, minden kodek .NET-ben implementálva.</li>
    <li>Képkockák megjelenítése BGRA pixelekre a modality LUT, a VOI LUT (ablak és szint) és a rétegek alkalmazásával a renderelő által.</li>
    <li>Adatkészletek sorosítása a DICOM JSON modellbe (PS3.18) és DICOM XML-be (PS3.19), és vissza, beleértve az aszinkron streamelést és a plug-in alapú tömeges adatbetöltést.</li>
    <li>Kommunikáció DIMSE-n keresztül kliens és szerver között: C-ECHO, C-STORE, C-FIND, C-MOVE, C-GET, az N-szolgáltatások és TLS.</li>
</ul>
</p>

<p>Aspose.Medical for .NET önálló. Nem szükséges DICOM néző, orvosi képalkotó szoftver vagy natív kodek telepítése. Alkalmas egészségügyi IT rendszerekhez, PACS integrációhoz, telemedicina platformokhoz és bármely olyan alkalmazáshoz, amelynek megbízhatóan kell feldolgoznia a DICOM adatokat.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     DICOM fájlok anonimizálása az adatvédelmi megfeleléshez
    </h2>
    <p>
     A betegadatok védelme szigorú követelmény az egészségügyi alkalmazásokban. Az Aspose.Medical for .NET a DICOM PS 3.15 titoktartási profiljaival anonimizálja a DICOM adatokat. Eltávolíthatja vagy cserélheti a betegazonosító információkat, miközben megőrzi a képalkotási adatok klinikai értékét, és kiválaszthatja, mit tart vissza egy profil: biztonságos privát attribútumok, UID-k, eszköz- és intézményazonosítók, betegjellemzők és hosszú távú időbeli információk. A <a href="/medical/net/anonymization/">DICOM anonimizálási oldal</a> részletesen mutatja a profil beállításait.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM fájl anonimizálása – C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     DICOM képkockák renderelése .NET C#-ban
    </h2>
    <p>
     Az Aspose.Medical for .NET egy DICOM képkockát 32-bit BGRA pixel képpé renderel. A renderelő alkalmazza a fotometrikus interpretációt, a modality LUT-ot és a VOI LUT-ot (ablak és szint) az adatkészletből, és megrajzolja a rétegeket, így az eredmény megegyezik a megjelenítő által mutatottal. A pixelek ezután az Öné: másolja őket egy pufferbe, és adja át bármely képalkotó könyvtárnak PNG, JPEG vagy TIFF mentéshez. Az egyetlen beépített képkódoló a könyvtárban a PNM. A konverziós oldalak teljes útvonalat mutatnak a <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a> és <a href="/medical/net/dicom-to-tiff/">TIFF</a> formátumokhoz.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM képkocka renderelése – C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Átkonvertálás transfer szintaxisok között
    </h2>
    <p>
     A képalkotó rendszerek és archívumok specifikus DICOM transfer szintaxisokat igényelnek. Az Aspose.Medical for .NET átkonvertálja a tömörítetlen formátumokat, a JPEG Baseline, JPEG Lossless, JPEG-LS, JPEG 2000, HTJ2K (High-Throughput JPEG 2000), JPEG XL és RLE formátumokat. A HTJ2K és a JPEG XL a DICOM szabvány legújabb két opciója, és itt .NET-ben vannak implementálva, mint minden más kodek. Az átkonvertálás fontos a PACS integrációhoz, az archívum méretéhez és a rendszerek közötti kompatibilitáshoz. Lásd a <a href="/medical/net/dicom-transfer-syntax-conversion/">transfer szintaxis konverziós oldalt</a> és a <a href="/medical/net/jpeg2000/">JPEG 2000 oldalt</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM HTJ2K-re átkonvertálása – C#
     </h3>
     <pre><code class="cs">// Load existing DICOM file
DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to High-Throughput JPEG 2000, lossless
DicomFile transcoded = dicomFile.Transcode(TransferSyntax.HTJ2KLossless);

// Save the transcoded file
transcoded.Save("output.dcm");</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     DICOM JSON és XML sorosítás
    </h2>
    <p>
     Az egészségügyi rendszerek webszolgáltatásokon keresztül cserélnek adatokat, ezért az Aspose.Medical for .NET sorosítja a DICOM adatkészleteket a DICOM JSON modellbe (PS3.18) és a DICOM XML-be (PS3.19), majd vissza is értelmezi őket adatkészletekké. A sorosítók stringeken, stream-eken és pipe-okon dolgoznak, szinkron és aszinkron módon, és a adatkészletek sorozata egyenként olvasható anélkül, hogy a teljes dokumentumot a memóriában tartaná. A tömeges adat hivatkozásokat egy plug-in alapú betöltő oldja fel, így a nagy pixel adatok kívül maradhatnak a dokumentumban. Lásd a <a href="/medical/net/dicom-to-json/">DICOM JSON</a> és <a href="/medical/net/dicom-to-xml/">DICOM XML</a> oldalakat.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM sorosítása JSON és XML formátumba – C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");
Dataset dataset = dicomFile.Dataset;

// Serialize the dataset to JSON (DICOM JSON Model) and to DICOM XML
string json = DicomJsonSerializer.Serialize(dataset, writeIndented: true);
string xml = DicomXmlSerializer.Serialize(dataset);

// Parse both back into datasets
Dataset? fromJson = DicomJsonSerializer.Deserialize(json);
Dataset fromXml = DicomXmlSerializer.Deserialize(xml);</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     DICOM hálózat DIMSE-en keresztül
    </h2>
    <p>
     Az Aspose.Medical for .NET közvetlenül kommunikál más DICOM rendszerekkel. A könyvtár DIMSE klienst és DIMSE szervert biztosít a C-ECHO, C-STORE, C-FIND, C-MOVE és C-GET szolgáltatásokhoz, valamint az N-szolgáltatásokhoz, az asszociációs egyeztetést bemutató kontextusokkal és szerepekkel, aszinkron műveleti ablakokkal, felhasználói azonosítási egyeztetéssel és TLS-szel. A kérések egy asszociáción belül sorba állnak, és a regisztrált kezelők válaszolnak rájuk, így egy store-and-forward csomópont, egy query proxy vagy egy teszt SCP néhány osztályból áll. A <a href="https://docs.aspose.com/medical/net/developer-guide/dicom-networking/">DICOM hálózati útmutató</a> lefedi a teljes API-t.
    </p>
