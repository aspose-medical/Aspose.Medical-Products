<p><strong>Aspose.Medical for .NET</strong>은 DICOM (Digital Imaging and Communications in Medicine) 파일을 다루기 위한 순수 .NET 클래스 라이브러리입니다. 개발자가 의료 영상 데이터를 읽고, 쓰고, 수정하고, 익명화하고, 트랜스코딩하고, 렌더링하며, DICOM JSON 및 DICOM XML로 직렬화하고, DIMSE 및 DICOMweb을 통해 다른 시스템과 연구를 교환할 수 있게 해줍니다. 외부 소프트웨어나 네이티브 종속성이 없습니다.</p>

<p>이 라이브러리는 관리되는 C#로 완전히 작성되었으며 Windows, Linux, macOS에서 .NET 10 위에서 실행됩니다. 네이티브 바이너리와 서드파티 NuGet 패키지가 없으므로 라이브러리는 단일 어셈블리로 배포되어 데스크톱 도구부터 클라우드 의료 시스템의 컨테이너까지 모든 .NET 애플리케이션에 사용할 수 있습니다.</p>

<p><strong>주요 기능:</strong>
<ul>
    <li>파일, 스트림 또는 파이프에서 DICOM 파일을 동기식 또는 비동기식으로 읽고 쓸 수 있으며, 모든 표준 데이터 요소와 값 표현을 완벽하게 지원합니다.</li>
    <li>대용량 파일의 메모리를 제어합니다: 모든 요소를 로드하거나, 큰 요소를 사용 시점까지 연기하거나, 요소를 건너뛰고 메타데이터만 읽습니다.</li>
    <li>시퀀스와 개인 태그를 포함한 모든 데이터 요소를 읽고 편집할 수 있으며, 비ASCII 텍스트에 대한 문자 집합 처리를 지원합니다.</li>
    <li>DICOM PS 3.15 보안 프로파일을 사용해 DICOM 파일을 익명화하며, UID, 날짜, 장치 및 기관 식별자, 환자 특성 유지 옵션을 제공합니다.</li>
    <li>전송 구문 간 트랜스코딩: JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL 및 RLE를 .NET에서 구현된 모든 코덱으로 지원합니다.</li>
    <li>모달리티 LUT, VOI LUT(윈도우 및 레벨) 및 오버레이가 적용된 렌더러를 사용해 프레임을 BGRA 픽셀로 렌더링합니다.</li>
    <li>DICOM JSON 모델(PS3.18) 및 DICOM XML(PS3.19)로 데이터셋을 직렬화하고 역직렬화하며, 비동기 스트리밍 및 플러그인식 대용량 데이터 로딩을 포함합니다.</li>
    <li>클라이언트와 서버 간 DIMSE 통신: C-ECHO, C-STORE, C-FIND, C-MOVE, C-GET, N-서비스 및 TLS를 지원합니다.</li>
    <li>QIDO-RS, WADO-RS, STOW-RS, 렌더링 이미지, WADO-URI 및 워크플로 서비스용 타입된 클라이언트를 사용해 모든 DICOMweb 서버에서 연구를 검색, 다운로드 및 업로드합니다.</li>
</ul>
</p>

<p>Aspose.Medical for .NET은 독립형입니다. DICOM 뷰어, 의료 영상 소프트웨어 및 네이티브 코덱을 설치할 필요가 없습니다. 의료 IT 시스템, PACS 통합, 원격 진료 플랫폼 및 DICOM 데이터를 신뢰성 있게 처리해야 하는 모든 애플리케이션에 적합합니다.</p>

    <h2 class="h2title">
     프라이버시 준수를 위한 DICOM 파일 익명화
    </h2>
    <p>
     환자 프라이버시는 의료 애플리케이션에서 필수 요구사항입니다. Aspose.Medical for .NET은 DICOM PS 3.15 보안 프로파일을 사용해 DICOM 데이터를 익명화합니다. 환자 식별 정보를 제거하거나 교체하면서도 영상 데이터의 임상적 가치를 유지할 수 있으며, 프로파일이 보유하도록 선택할 수 있습니다: 안전한 개인 속성, UID, 장치 및 기관 식별자, 환자 특성, 그리고 장기 시간 정보. <a href="/medical/net/anonymization/">DICOM 익명화 페이지</a>에서 프로파일 옵션을 자세히 확인할 수 있습니다.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM 파일 익명화 - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>

     Aspose.Medical for .NET은 DICOM 프레임을 32비트 BGRA 픽셀 이미지로 렌더링합니다. 렌더러는 데이터셋에서 광도 해석, 모달리티 LUT 및 VOI LUT(윈도우 및 레벨)를 적용하고 오버레이를 그려, 뷰어가 표시하는 결과와 동일하게 만듭니다. 픽셀은 귀하의 것이므로 버퍼에 복사하여 any 이미지 라이브러리로 전달해 PNG, JPEG 또는 TIFF로 저장할 수 있습니다. 라이브러리에 내장된 이미지 인코더는 PNM 하나뿐입니다. 변환 페이지에서 <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a>, <a href="/medical/net/dicom-to-tiff/">TIFF</a> 전체 경로를 확인할 수 있습니다.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM 프레임 렌더링 - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>

    <h2 class="h2title">
     전송 구문 간 트랜스코딩
    </h2>
    <p>
     영상 시스템과 아카이브는 특정 DICOM 전송 구문을 필요로 합니다. Aspose.Medical for .NET은 무압축 형식, JPEG Baseline, JPEG 무손실, JPEG-LS, JPEG 2000, HTJ2K(고속 JPEG 2000), JPEG XL 및 RLE 간에 트랜스코딩합니다. HTJ2K와 JPEG XL은 DICOM 표준에서 가장 최신 옵션이며, 다른 코덱과 마찬가지로 .NET에서 구현되었습니다. 트랜스코딩은 PACS 통합, 아카이브 크기 및 시스템 간 호환성에 중요합니다. <a href="/medical/net/dicom-transfer-syntax-conversion/">전송 구문 변환 페이지</a>와 <a href="/medical/net/jpeg2000/">JPEG 2000 페이지</a>를 참고하십시오.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM을 HTJ2K로 트랜스코딩 - C#
     </h3>
     <pre><code class="cs">// Load existing DICOM file
DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to High-Throughput JPEG 2000, lossless
DicomFile transcoded = dicomFile.Transcode(TransferSyntax.HTJ2KLossless);

// Save the transcoded file
transcoded.Save("output.dcm");</code></pre>

    <h2 class="h2title">
     DICOM을 JSON 및 XML로 직렬화
    </h2>
    <p>
     헬스케어 시스템은 웹 서비스를 통해 데이터를 교환하므로 Aspose.Medical for .NET은 DICOM 데이터셋을 DICOM JSON 모델(PS3.18) 및 DICOM XML(PS3.19)로 직렬화하고, 이를 다시 데이터셋으로 파싱합니다. 직렬화기는 문자열, 스트림 및 파이프에서 동기식 및 비동기식으로 작동하며, 전체 문서를 메모리에 보관하지 않고 데이터셋을 하나씩 읽을 수 있습니다. 대용량 데이터 참조는 플러그인식 로더를 통해 해결되어 대용량 픽셀 데이터를 문서 외부에 유지할 수 있습니다. <a href="/medical/net/dicom-to-json/">DICOM to JSON</a> 및 <a href="/medical/net/dicom-to-xml/">DICOM to XML</a> 페이지를 참고하십시오.
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM을 JSON 및 XML로 직렬화 - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");
Dataset dataset = dicomFile.Dataset;

// Serialize the dataset to JSON (DICOM JSON Model) and to DICOM XML
string json = DicomJsonSerializer.Serialize(dataset, writeIndented: true);
string xml = DicomXmlSerializer.Serialize(dataset);

// Parse both back into datasets
Dataset? fromJson = DicomJsonSerializer.Deserialize(json);
Dataset fromXml = DicomXmlSerializer.Deserialize(xml);</code></pre>

     DIMSE를 통한 DICOM 네트워킹
    </h2>
    <p>
     Aspose.Medical for .NET은 다른 DICOM 시스템과 직접 통신합니다. 라이브러리는 C-ECHO, C-STORE, C-FIND, C-MOVE 및 C-GET을 위한 DIMSE 클라이언트와 서버를 제공하며, N-서비스, 프레젠테이션 컨텍스트 및 역할을 포함한 연결 협상, 비동기 작업 윈도우, 사용자 인증 협상 및 TLS를 지원합니다. 요청은 연결에 큐잉되고 등록한 핸들러가 응답하므로, 스토어-앤-포워드 노드, 쿼리 프록시 또는 테스트 SCP를 몇 개의 클래스만으로 구현할 수 있습니다. <a href="https://docs.aspose.com/medical/net/developer-guide/dicom-networking/">DICOM 네트워킹 가이드</a>에서 전체 API를 확인할 수 있습니다.
    </p>
    <div class="codeblock" id="code">
     <h3>
      C-STORE를 사용해 PACS에 연구 전송 - C#

     <pre><code class="cs">DicomFile dicomFile = DicomFile.Open("study.dcm");

DicomNetworkClient client = DicomNetworkClient
    .CreateBuilder(new DicomNetworkClientOptions
    {
        Called = "PACS_AE",
        Calling = "CLIENT_AE",
        Connection = new DicomNetworkConnectionOptions
        {
            TargetHost = new IPEndPoint(IPAddress.Parse("192.0.2.10"), 104)
        },
        AssociationNegotiation = new AssociationNegotiationOptions()
            .WithPresentationContext(new PresentationContext

client.QueueRequest(new CStoreRequest(dicomFile.Dataset, TransferSyntax.ExplicitVrLittleEndian));

await client.SendAsync(CancellationToken.None);
await client.StopAsync();</code></pre>
