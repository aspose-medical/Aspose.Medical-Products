{{< blocks/products/pf/feature-page-section h2="JPEG 2000 στην Ιατρική Απεικόνιση">}}

<p><strong>JPEG 2000</strong> (ISO/IEC 15444) είναι το πιο ευρέως χρησιμοποιούμενο πρότυπο συμπίεσης βασισμένο σε κυματισμούς στην ιατρική απεικόνιση. Σε αντίθεση με το παραδοσιακό JPEG, προσφέρει τόσο lossless όσο και lossy συμπίεση σε έναν ενιαίο κωδικοποιητή, προοδευτική αποκωδικοποίηση για πρόσβαση σε περιοχές ενδιαφέροντος, και ανώτερες αναλογίες συμπίεσης &mdash; καθιστώντας το ιδανικό για αρχειοθέτηση μεγάλων μελετών και μετάδοση εικόνων μέσω περιορισμένων δικτύων.</p>

<p><strong>Aspose.Medical for .NET</strong> παρέχει μια καθαρή υλοποίηση σε C# του κωδικοποιητή JPEG 2000 χωρίς εγγενείς εξαρτήσεις. Η βιβλιοθήκη μπορεί να διαβάσει, να αποδώσει και να μετακωδικοποιήσει αρχεία DICOM συμπιεσμένα με οποιαδήποτε από τις τέσσερις τυπικές συντακτικές μονάδες μεταφοράς JPEG 2000.</p>

{{< blocks/products/pf/feature-page-section h2="Δεδομένα Εικονοστοιχείων 8‑Bit και 16‑Bit">}}

<p>Οι ιατρικές εικόνες συχνά χρησιμοποιούν 16 bits ανά δείγμα για να καταγράψουν το πλήρες δυναμικό εύρος των μοδάλων όπως CT (συνήθως 12‑bit αποθηκευμένα σε 16‑bit) και MRI. Το Aspose.Medical διαχειρίζεται και τις δύο βάθους bit για JPEG 2000:</p>

<ul>
<li><strong>Ανάγνωση (αποσυμπίεση)</strong>: αρχεία μονόχρωμα 16‑bit (CT, MRI, ακτινογραφία) και χρωματικά αρχεία τριών συστατικών 8‑bit (RGB, YBR_RCT, YBR_ICT). Παλέτες, CMYK, προφίλ ICC και υποδειγματοληψία χρωματικών ροών κώδικα απορρίπτονται με ξεκάθαρη εξαίρεση αντί για σιωπηρή λανθασμένη εικόνα.</li>
<li><strong>Γραφή (συμπίεση)</strong>: εικόνες μονόχρωμες 16‑bit και RGB 8‑bit. Κωδικοποίηση 8‑bit μονόχρωμη και 16‑bit έγχρωμη δεν είναι διαθέσιμες· χρησιμοποιήστε HTJ2K ή JPEG XL για αυτές, και τα δύο δέχονται μονόχρωμη και έγχρωμη σε οποιοδήποτε βάθος bit.</li>
</ul>

<div class="codeblock" id="code">
 <h3>Ανάγνωση και επιθεώρηση DICOM συμπιεσμένων με JPEG 2000 - C#</h3>

if (ts is null)
    return; // the file meta information carries no transfer syntax
Console.WriteLine($"Transfer Syntax: {ts}");
Console.WriteLine($"Encapsulated: {ts.IsEncapsulated}");
Console.WriteLine($"Lossy: {ts.IsLossy}");

// Inspect pixel data bit depth
PixelData pixelData = PixelData.Create(dicomFile.Dataset);
Console.WriteLine($"Bits Allocated: {pixelData.BitsAllocated}");
Console.WriteLine($"Bits Stored: {pixelData.BitsStored}");
Console.WriteLine($"High Bit: {pixelData.HighBit}");
Console.WriteLine($"Samples Per Pixel: {pixelData.SamplesPerPixel}");</code></pre>

{{< blocks/products/pf/feature-page-section h2="Μετακωδικοποίηση σε JPEG 2000">}}

<p>Χρησιμοποιήστε τη μέθοδο <code>Transcode</code> για να συμπιέσετε οποιοδήποτε αρχείο DICOM σε JPEG 2000 ή για να μετατρέψετε μεταξύ των λειτουργιών JPEG 2000:</p>

<div class="codeblock" id="code">
 <h3>Συμπίεση DICOM σε JPEG 2000 Lossless - C#</h3>
 <pre><code class="cs">// Load an uncompressed DICOM file
DicomFile dicomFile = DicomFile.Open("uncompressed.dcm");

// Transcode to JPEG 2000 Lossless — no quality loss, reduced file size
DicomFile lossless = dicomFile.Transcode(TransferSyntax.Jpeg2000Lossless);
lossless.Save("j2k_lossless.dcm");</code></pre>
</div>

<div class="codeblock" id="code">
 <h3>Συμπίεση DICOM σε JPEG 2000 Lossy - C#</h3>
 <pre><code class="cs">// Load a DICOM file
DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to JPEG 2000 Lossy — smaller file size for transmission
DicomFile lossy = dicomFile.Transcode(TransferSyntax.Jpeg2000Lossy);
lossy.Save("j2k_lossy.dcm");</code></pre>
</div>

{{< blocks/products/pf/feature-page-section h2="JPEG 2000 Υψηλής Διαπερατότητας (HTJ2K)">}}

<p>Το HTJ2K (ISO/IEC 15444-15) αντικαθιστά τον αργό αριθμητικό κωδικοποιητή του JPEG 2000 με έναν ταχύτερο κωδικοποιητή κατά μπλοκ. Διατηρεί τον ίδιο μετασχηματισμό κυματιδίου, τις σειρές προόδου και την ποιότητα, και αποκωδικοποιεί και κωδικοποιεί πολλές φορές πιο γρήγορα. Το Aspose.Medical υλοποιεί και τις τρεις συντακτικές μονάδες μεταφοράς DICOM HTJ2K σε καθαρό .NET, για μονόχρωμες και έγχρωμες εικόνες, και μετακωδικοποιεί μεταξύ HTJ2K και κάθε άλλης υποστηριζόμενης σύνταξης:</p>

<ul>
<li><code>HTJ2KLossless</code> (1.2.840.10008.1.2.4.201) &mdash; μόνο lossless</li>
<li><code>HTJ2KLosslessRPCL</code> (1.2.840.10008.1.2.4.202) &mdash; lossless με σειρά προόδου RPCL</li>
<li><code>HTJ2K</code> (1.2.840.10008.1.2.4.203) &mdash; lossy ή lossless</li>
</ul>

<div class="codeblock" id="code">
 <h3>Μετακωδικοποίηση JPEG 2000 σε HTJ2K και αντίστροφα - C#</h3>
 <pre><code class="cs">// Transcode a JPEG 2000 file to HTJ2K, and back to classic JPEG 2000
DicomFile j2kFile = DicomFile.Open("j2k_lossless.dcm");
DicomFile htj2kFile = j2kFile.Transcode(TransferSyntax.HTJ2KLossless);
htj2kFile.Save("htj2k_lossless.dcm");

// HTJ2K with RPCL progression order, lossless
DicomFile rpclFile = j2kFile.Transcode(TransferSyntax.HTJ2KLosslessRPCL);
rpclFile.Save("htj2k_rpcl.dcm");

// HTJ2K lossy
DicomFile htj2kLossy = j2kFile.Transcode(TransferSyntax.HTJ2K);
htj2kLossy.Save("htj2k_lossy.dcm");

// Any HTJ2K file decodes back to an uncompressed transfer syntax
DicomFile uncompressed = htj2kFile.Transcode(TransferSyntax.ExplicitVrLittleEndian);
uncompressed.Save("decoded.dcm");</code></pre>
</div>
