<p><strong>Aspose.Medical for .NET</strong> एक शुद्ध .NET क्लास लाइब्रेरी है जो DICOM (Digital Imaging and Communications in Medicine) फ़ाइलों के साथ काम करने के लिए है। यह डेवलपर्स को मेडिकल इमेजिंग डेटा को पढ़ने, लिखने, संशोधित करने, अनामित करने, ट्रांसकोड करने और रेंडर करने, इसे DICOM JSON और DICOM XML में सीरियलाइज़ करने, तथा DIMSE के माध्यम से अन्य सिस्टम्स के साथ स्टडीज़ का आदान‑प्रदान करने की सुविधा देती है, बिना किसी बाहरी सॉफ़्टवेयर या मूल निर्भरताओं के।</p>

<p>यह लाइब्रेरी पूरी तरह से मैनेज्ड C# में लिखी गई है और .NET 10 पर Windows, Linux और macOS पर चलती है। यहाँ कोई मूल बाइनरी नहीं है और कोई थर्ड‑पार्टी NuGet पैकेज नहीं है, इसलिए लाइब्रेरी एक ही असेंबली के रूप में किसी भी .NET एप्लिकेशन में तैनात की जा सकती है, डेस्कटॉप टूल से लेकर क्लाउड हेल्थकेयर सिस्टम में कंटेनर तक।</p>

<p><strong>मुख्य विशेषताएँ:</strong>
<ul>
    <li>फ़ाइल, स्ट्रीम या पाइप से DICOM फ़ाइलों को सिंक्रोनस या असिंक्रोनस रूप में पढ़ें और लिखें, सभी मानक डेटा तत्वों और वैल्यू रिप्रेजेंटेशन के पूर्ण समर्थन के साथ।</li>
    <li>बड़े फ़ाइलों पर मेमोरी नियंत्रित करें: प्रत्येक तत्व को लोड करें, बड़े तत्वों को तब तक स्थगित रखें जब तक उनका उपयोग न हो, या उन्हें छोड़ दें और केवल मेटाडेटा पढ़ें।</li>
    <li>किसी भी डेटा तत्व को पढ़ें और संपादित करें, जिसमें सीक्वेंसेज़ और निजी टैग शामिल हैं, अस ASCII टेक्स्ट के लिए कैरेक्टर सेट हैंडलिंग के साथ।</li>
    <li>DICOM PS 3.15 के गोपनीयता प्रोफ़ाइल के साथ DICOM फ़ाइलों को अनामित करें, UIDs, तिथियों, डिवाइस और संस्थान पहचानकर्ताओं तथा रोगी विशेषताओं को बनाए रखने के विकल्पों के साथ।</li>
    <li>ट्रांसफ़र सिंटैक्स के बीच ट्रांसकोड करें: JPEG, JPEG‑LS, JPEG 2000, HTJ2K, JPEG XL और RLE, जहाँ हर कोडेक .NET में लागू है।</li>
    <li>मोडैलिटी LUT, VOI LUT (विंडो और लेवल) और रेंडरर द्वारा लागू ओवरलेज़ के साथ फ्रेम्स को BGRA पिक्सेल में रेंडर करें।</li>
    <li>डेटासेट को DICOM JSON मॉडल (PS3.18) और DICOM XML (PS3.19) में तथा वापस सीरियलाइज़ करें, असिंक्रोनस स्ट्रीमिंग और प्लगेबल बल्क डेटा लोडिंग सहित।</li>
    <li>एक क्लाइंट और सर्वर के साथ DIMSE के माध्यम से संचार करें: C‑ECHO, C‑STORE, C‑FIND, C‑MOVE, C‑GET, N‑services, और TLS।</li>
</ul>
</p>

<p>Aspose.Medical for .NET स्वतंत्र है। इसे किसी DICOM व्यूअर, मेडिकल इमेजिंग सॉफ़्टवेयर या मूल कोडेक्स की आवश्यकता नहीं है। यह हेल्थकेयर आईटी सिस्टम्स, PACS इंटेग्रेशन, टेलीमेडिसिन प्लेटफ़ॉर्म और किसी भी एप्लिकेशन में फिट बैठता है जिसे DICOM डेटा को विश्वसनीय रूप से प्रोसेस करना होता है।</p>

     रोगी गोपनीयता हेल्थकेयर एप्लिकेशन्स में एक कठोर आवश्यकता है। Aspose.Medical for .NET DICOM PS 3.15 के गोपनीयता प्रोफ़ाइल्स के साथ DICOM डेटा को अनामित करता है। आप इमेजिंग डेटा के क्लीनिकल मूल्य को बनाए रखते हुए रोगी की पहचान करने वाली जानकारी को हटा या बदल सकते हैं, और आप चुन सकते हैं कि प्रोफ़ाइल क्या रखे: सुरक्षित निजी एट्रिब्यूट्स, UIDs, डिवाइस और संस्थान पहचानकर्ता, रोगी विशेषताएँ, तथा लॉन्गिट्यूडिनल टेम्पोरल जानकारी। <a href="/medical/net/anonymization/">DICOM अनामिकरण पृष्ठ</a> प्रोफ़ाइल विकल्पों को विस्तार से दिखाता है।
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM फ़ाइल को अनामित करें - C#

     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>
