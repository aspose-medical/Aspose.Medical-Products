<p><strong>Aspose.Medical for .NET</strong> は、DICOM（Digital Imaging and Communications in Medicine）ファイルを扱う純粋な .NET クラスライブラリです。開発者は医療画像データの読み取り、書き込み、変更、匿名化、トランスコード、レンダリングを行い、DICOM JSON と DICOM XML にシリアライズし、DIMSE および DICOMweb を介して他システムとスタディを交換できます。外部ソフトウェアやネイティブ依存は不要です。</p>

<p>このライブラリは完全にマネージド C# で記述され、Windows、Linux、macOS 上の .NET 10 で動作します。ネイティブバイナリやサードパーティ製 NuGet パッケージは不要で、単一アセンブリとして任意の .NET アプリケーション（デスクトップツールからクラウド医療システムのコンテナまで）にデプロイできます。</p>

<p><strong>主な機能:</strong>
<ul>
    <li>ファイル、ストリーム、パイプから DICOM ファイルを同期的または非同期的に読み書きし、すべての標準データ要素と値表現を完全にサポートします。</li>
    <li>大容量ファイルのメモリ制御：すべての要素をロードするか、大きな要素を使用時まで遅延させるか、あるいはスキップしてメタデータだけを読み取ります。</li>
    <li>シーケンスやプライベートタグを含む任意のデータ要素を読み取り・編集し、非 ASCII テキストの文字セットも適切に処理します。</li>
    <li>DICOM PS 3.15 の機密性プロファイルを使用して DICOM ファイルを匿名化し、UID、日付、デバイス・機関識別子、患者属性を保持するオプションを提供します。</li>
    <li>転送構文間のトランスコード：JPEG、JPEG-LS、JPEG 2000、HTJ2K、JPEG XL、RLE をサポートし、すべてのコーデックが .NET で実装されています。</li>
    <li>モダリティ LUT、VOI LUT（ウィンドウ・レベル）およびオーバーレイを適用したレンダラでフレームを BGRA ピクセルに変換します。</li>
    <li>DICOM JSON Model (PS3.18) および DICOM XML (PS3.19) にデータセットをシリアライズし、非同期ストリーミングやプラグイン可能なバルクデータロードを含めて双方向に変換します。</li>
    <li>クライアントとサーバー間で DIMSE 通信を行い、C-ECHO、C-STORE、C-FIND、C-MOVE、C-GET、N-サービス、TLS をサポートします。</li>
    <li>モダリティワークリストの照会、MPPS の報告、UPS-RS ワークアイテムによる作業割り当てをクライアント・サーバー双方で行えます。</li>
    <li>QIDO-RS、WADO-RS、STOW-RS、レンダリング画像、WADO-URI、ワークフローサービス用の型付きクライアントで、任意の DICOMweb サーバー上のスタディを検索、ダウンロード、アップロードできます。</li>
    <li>独自の DICOMweb サーバーを構築できます：ASP.NET Core もしくは任意の HTTP ホスト上で QIDO-RS、WADO-RS、STOW-RS、ワークフローサービスを提供し、バックエンドにストレージを配置します。</li>
</ul>
</p>

<p>Aspose.Medical for .NET は自己完結型です。DICOM ビューアや医療画像ソフトウェア、ネイティブコーデックのインストールは不要です。医療ITシステム、PACS 統合、遠隔医療プラットフォーム、及び DICOM データを確実に処理する必要があるあらゆるアプリケーションに適しています。</p>

    <h2 class="h2title">
     プライバシー遵守のための DICOM ファイル匿名化
    </h2>
    <p>
     患者プライバシーは医療アプリケーションにおいて厳格な要件です。Aspose.Medical for .NET は DICOM PS 3.15 の機密性プロファイルを使用して DICOM データを匿名化します。画像データの臨床的価値を保持しつつ、患者識別情報を削除または置換でき、プロファイルが保持する項目（安全なプライベート属性、UID、デバイス・機関識別子、患者特性、長期的時間情報）を選択できます。<a href="/medical/net/anonymization/">DICOM 匿名化ページ</a>でプロファイルオプションの詳細をご確認ください。
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM ファイルの匿名化 - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>

    <h2 class="h2title">
     .NET C# で DICOM フレームをレンダリング
    </h2>
    <p>
     Aspose.Medical for .NET は DICOM フレームを 32 ビット BGRA ピクセル画像にレンダリングします。レンダラはデータセットから写真測定解釈、モダリティ LUT、VOI LUT（ウィンドウとレベル）を適用し、オーバーレイを描画するため、結果はビューアが表示するものと同一になります。生成されたピクセルは自由に利用でき、バッファにコピーして任意の画像ライブラリに渡し、PNG、JPEG、TIFF として保存できます。ライブラリに組み込まれている唯一の画像エンコーダは PNM です。変換ページでは <a href="/medical/net/dicom-to-png/">PNG</a>、<a href="/medical/net/dicom-to-jpg/">JPEG</a>、<a href="/medical/net/dicom-to-tiff/">TIFF</a> の全手順を示しています。
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM フレームのレンダリング - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>

    <h2 class="h2title">
     転送構文間のトランスコード
    </h2>
    <p>
     医用画像システムやアーカイブでは特定の DICOM 転送構文が必要です。Aspose.Medical for .NET は非圧縮形式、JPEG Baseline、JPEG Extended、JPEG Lossless、JPEG-LS、JPEG 2000、HTJ2K（ハイスループット JPEG 2000）、JPEG XL、RLE 間のトランスコードをサポートします。HTJ2K と JPEG XL は DICOM 標準の最新オプションで、他のコーデックと同様に .NET で実装されています。トランスコードは PACS 統合、アーカイブサイズ、システム間互換性に重要です。<a href="/medical/net/dicom-transfer-syntax-conversion/">転送構文変換ページ</a>と<a href="/medical/net/jpeg2000/">JPEG 2000 ページ</a>をご参照ください。

DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to High-Throughput JPEG 2000, lossless

// Save the transcoded file
transcoded.Save("output.dcm");</code></pre>

   <div class="col-lg-12">
    <h2 class="h2title">
     DICOM の JSON および XML シリアライズ
    </h2>
    <p>
     医療システムは Web サービスを通じてデータを交換するため、Aspose.Medical for .NET は DICOM データセットを DICOM JSON Model (PS3.18) および DICOM XML (PS3.19) にシリアライズし、両方をデータセットに復元します。シリアライザは文字列、ストリーム、パイプ上で同期・非同期に動作し、データセットのシーケンスをメモリに全体を保持せずに逐次読み取れます。バルクデータ参照はプラグイン可能なローダーで解決され、大容量ピクセルデータをドキュメント外に保持できます。<a href="/medical/net/dicom-to-json/">DICOM to JSON</a> と <a href="/medical/net/dicom-to-xml/">DICOM to XML</a> のページをご覧ください。
    </p>
    <div class="codeblock" id="code">
     <h3>
      DICOM を JSON と XML にシリアライズ - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");
Dataset dataset = dicomFile.Dataset;

// Serialize the dataset to JSON (DICOM JSON Model) and to DICOM XML
string json = DicomJsonSerializer.Serialize(dataset, writeIndented: true);
string xml = DicomXmlSerializer.Serialize(dataset);

// Parse both back into datasets
Dataset? fromJson = DicomJsonSerializer.Deserialize(json);
