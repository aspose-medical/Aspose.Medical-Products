<p><strong>Aspose.Medical for .NET</strong> es una biblioteca de clases .NET pura para trabajar con archivos DICOM (Digital Imaging and Communications in Medicine). Permite a los desarrolladores leer, escribir, modificar, anonimizar, transcodificar y renderizar datos de imágenes médicas, serializarlos a DICOM JSON y DICOM XML, e intercambiar estudios con otros sistemas a través de DIMSE, sin ningún software externo ni dependencias nativas.</p>

<p>La biblioteca está escrita completamente en C# gestionado y se ejecuta en .NET 10 en Windows, Linux y macOS. No hay binarios nativos ni paquetes NuGet de terceros, por lo que la biblioteca se despliega como un solo ensamblado en cualquier aplicación .NET, desde una herramienta de escritorio hasta un contenedor en un sistema de salud en la nube.</p>

<p><strong>Características principales:</strong>
<ul>
    <li>Leer y escribir archivos DICOM desde un archivo, un flujo o una tubería, de forma síncrona o asíncrona, con soporte completo para todos los elementos de datos estándar y representaciones de valor.</li>
    <li>Control de memoria en archivos grandes: cargar cada elemento, aplazar los elementos grandes hasta que se usen, o omitirlos y leer solo los metadatos.</li>
    <li>Leer y editar cualquier elemento de datos, incluidas secuencias y etiquetas privadas, con manejo de conjuntos de caracteres para texto no ASCII.</li>
    <li>Anonimizar archivos DICOM con los perfiles de confidencialidad de DICOM PS 3.15, con opciones para conservar UIDs, fechas, identificadores de dispositivos e instituciones y características del paciente.</li>
    <li>Transcodificar entre sintaxis de transferencia: JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL y RLE, con todos los códecs implementados en .NET.</li>
    <li>Renderizar fotogramas a píxeles BGRA con la LUT de modalidad, la LUT VOI (ventana y nivel) y superposiciones aplicadas por el renderizador.</li>
    <li>Serializar conjuntos de datos al Modelo DICOM JSON (PS3.18) y a DICOM XML (PS3.19) y viceversa, incluyendo transmisión asíncrona y carga de datos masivos mediante complementos.</li>
    <li>Comunicar a través de DIMSE con un cliente y un servidor: C-ECHO, C-STORE, C-FIND, C-MOVE, C-GET, los servicios N y TLS.</li>
</ul>
</p>

<p>Aspose.Medical for .NET es autónomo. No requiere visor DICOM, software de imágenes médicas ni códecs nativos instalados. Se adapta a los sistemas de TI en salud, integración PACS, plataformas de telemedicina y cualquier aplicación que necesite procesar datos DICOM de forma fiable.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     Biblioteca .NET pura - Cero dependencias
    </h2>
    <p>
     Aspose.Medical for .NET está escrito completamente en C# gestionado y se distribuye como un solo ensamblado sin binarios nativos ni paquetes NuGet de terceros. Otras bibliotecas de imágenes médicas dependen de códecs nativos o herramientas externas; esta no. Todos los códecs de compresión de imágenes (JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL, RLE) están implementados en .NET, por lo que la biblioteca se comporta igual en Windows, Linux y macOS. Esto la hace adecuada para contenedores, entornos en la nube y cualquier despliegue donde instalar bibliotecas nativas no sea una opción. El paquete tiene como objetivo .NET 10.
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Anonimizar archivos DICOM para el cumplimiento de privacidad
    </h2>
    <p>
     La privacidad del paciente es un requisito estricto en aplicaciones de salud. Aspose.Medical for .NET anonimiza datos DICOM con los perfiles de confidencialidad de DICOM PS 3.15. Puede eliminar o reemplazar la información de identificación del paciente manteniendo el valor clínico de los datos de imágenes, y puede elegir qué retiene un perfil: atributos privados seguros, UIDs, identificadores de dispositivo e institución, características del paciente e información temporal longitudinal. La <a href="/medical/net/anonymization/">página de anonimización DICOM</a> muestra en detalle las opciones de perfil.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Anonimizar archivo DICOM - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Renderizar fotogramas DICOM en .NET C#
    </h2>
    <p>
     Aspose.Medical for .NET renderiza un fotograma DICOM en una imagen de píxeles BGRA de 32 bits. El renderizador aplica la interpretación fotométrica, la LUT de modalidad y la LUT VOI (ventana y nivel) del conjunto de datos y dibuja las superposiciones, de modo que el resultado coincide con lo que muestra un visor. Los píxeles son suyos: cópielos en un búfer y páselos a cualquier biblioteca de imágenes para guardar PNG, JPEG o TIFF. El único codificador de imágenes incorporado en la biblioteca es PNM. Las páginas de conversión muestran la ruta completa para <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a> y <a href="/medical/net/dicom-to-tiff/">TIFF</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Renderizar un fotograma DICOM - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     Transcodificar entre sintaxis de transferencia
    </h2>
    <p>
     Los sistemas de imágenes y archivos requieren sintaxis de transferencia DICOM específicas. Aspose.Medical for .NET transcodifica entre formatos sin comprimir, JPEG Baseline, JPEG Lossless, JPEG-LS, JPEG 2000, HTJ2K (High-Throughput JPEG 2000), JPEG XL y RLE. HTJ2K y JPEG XL son las dos opciones más recientes del estándar DICOM, y aquí están implementadas en .NET como cualquier otro códec. La transcodificación es importante para la integración PACS, el tamaño del archivo y la compatibilidad entre sistemas. Consulte la <a href="/medical/net/dicom-transfer-syntax-conversion/">página de conversión de sintaxis de transferencia</a> y la <a href="/medical/net/jpeg2000/">página JPEG 2000</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Transcodificar DICOM a HTJ2K - C#
     </h3>
     <pre><code class="cs">// Load existing DICOM file
DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to High-Throughput JPEG 2000, lossless
DicomFile transcoded = dicomFile.Transcode(TransferSyntax.HTJ2KLossless);

// Save the transcoded file
transcoded.Save("output.dcm");</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     Serialización DICOM a JSON y XML
    </h2>
    <p>
     Los sistemas de salud intercambian datos mediante servicios web, por lo que Aspose.Medical for .NET serializa conjuntos de datos DICOM al Modelo DICOM JSON (PS3.18) y a DICOM XML (PS3.19), y los analiza de vuelta a conjuntos de datos. Los serializadores funcionan con cadenas, flujos y tuberías, de forma síncrona y asíncrona, y una secuencia de conjuntos de datos puede leerse uno a uno sin mantener todo el documento en memoria. Las referencias de datos masivos se resuelven mediante un cargador plug‑in, de modo que los datos de píxeles grandes pueden permanecer fuera del documento. Véase las páginas <a href="/medical/net/dicom-to-json/">DICOM a JSON</a> y <a href="/medical/net/dicom-to-xml/">DICOM a XML</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Serializar DICOM a JSON y XML - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");
Dataset dataset = dicomFile.Dataset;

// Serialize the dataset to JSON (DICOM JSON Model) and to DICOM XML
string json = DicomJsonSerializer.Serialize(dataset, writeIndented: true);
string xml = DicomXmlSerializer.Serialize(dataset);

// Parse both back into datasets
Dataset? fromJson = DicomJsonSerializer.Deserialize(json);
Dataset fromXml = DicomXmlSerializer.Deserialize(xml);</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     Redes DICOM sobre DIMSE
    </h2>
    <p>
     Aspose.Medical for .NET se comunica directamente con otros sistemas DICOM. La biblioteca proporciona un cliente DIMSE y un servidor DIMSE para C-ECHO, C-STORE, C-FIND, C-MOVE y C-GET, junto con los N‑services, negociación de asociación con contextos de presentación y roles, ventanas de operación asíncronas, negociación de identidad de usuario y TLS. Las solicitudes se encolan en una asociación y son respondidas por manejadores que usted registre, por lo que un nodo store‑and‑forward, un proxy de consulta o un SCP de prueba se implementan con unas pocas clases. La <a href="https://docs.aspose.com/medical/net/developer-guide/dicom-networking/">guía de redes DICOM</a> cubre toda la API.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Enviar un estudio a un PACS con C-STORE - C#
     </h3>
     <pre><code class="cs">DicomFile dicomFile = DicomFile.Open("study.dcm");

DicomNetworkClient client = DicomNetworkClient
    .CreateBuilder(new DicomNetworkClientOptions
    {
        Called = "PACS_AE",
        Calling = "CLIENT_AE",
        Connection = new DicomNetworkConnectionOptions
        {
            TargetHost = new IPEndPoint(IPAddress.Parse("192.0.2.10"), 104)
        },
        AssociationNegotiation = new AssociationNegotiationOptions()
            .WithPresentationContext(new PresentationContext
            {
                AbstractSyntax = Uid.CTImageStorage,
                Role = null,
                TransferSyntaxes = ImmutableArray.Create(TransferSyntax.ExplicitVrLittleEndian)
            })
    })
    .Build();

client.QueueRequest(new CStoreRequest(dicomFile.Dataset, TransferSyntax.ExplicitVrLittleEndian));

await client.SendAsync(CancellationToken.None);
await client.StopAsync();</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     Archivos DICOM grandes sin gran uso de memoria
    </h2>
    <p>
     Las imágenes de diapositiva completa, series largas y estudios multi‑frame no caben cómodamente en memoria. Aspose.Medical for .NET le permite decidir cuánto de un archivo se carga: leer todo, aplazar elementos por encima de un umbral de tamaño hasta que se accedan, o omitirlos y trabajar solo con los metadatos. Leer desde un flujo o tubería y escribir de la misma manera mantiene los datos en movimiento en lugar de acumularse. La <a href="https://docs.aspose.com/medical/net/developer-guide/open-dicom-file/memory-management/">guía de gestión de memoria</a> explica los compromisos.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Leer metadatos sin datos de píxeles - C#
     </h3>
     <pre><code class="cs">// Elements larger than the threshold are not loaded into memory
DicomFile metadataOnly = DicomFile.Open(
    "whole_slide.dcm",
    ReadDicomFileOptions.Default,
    TagDataReadingStrategies.SkipLargeTags());

string? patientName = metadataOnly.Dataset.GetSingleValueOrDefault(Tag.PatientName, string.Empty);</code></pre>
