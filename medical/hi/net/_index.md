<p><strong>Aspose.Medical for .NET</strong> एक शुद्ध .NET क्लास लाइब्रेरी है जो DICOM (Digital Imaging and Communications in Medicine) फ़ाइलों के साथ काम करने के लिए बनाई गई है। यह डेवलपर्स को DICOM डेटा को पढ़ने, लिखने, संशोधित करने, अनामित करने, ट्रांसकोड करने और रेंडर करने, उसे DICOM JSON और DICOM XML में सीरियलाइज़ करने, और DIMSE तथा DICOMweb के माध्यम से अन्य सिस्टमों के साथ स्टडीज़ का आदान‑प्रदान करने की सुविधा देती है, बिना किसी बाहरी सॉफ़्टवेयर या नेटिव डिपेंडेंसी के।</p>

<p>यह लाइब्रेरी पूरी तरह से प्रबंधित C# में लिखी गई है और .NET 10 पर Windows, Linux और macOS पर चलती है। इसमें कोई नेटिव बाइनरी नहीं है और कोई थर्ड‑पार्टी NuGet पैकेज नहीं है, इसलिए लाइब्रेरी को किसी भी .NET एप्लिकेशन में एक ही एसेम्बली के रूप में डिप्लॉय किया जा सकता है, चाहे वह डेस्कटॉप टूल हो या क्लाउड हेल्थकेयर सिस्टम में कंटेनर।</p>

<p><strong>मुख्य विशेषताएँ:</strong>
<ul>
    <li>फ़ाइल, स्ट्रीम या पाइप से DICOM फ़ाइलें पढ़ें और लिखें, सिंक्रोनस या एसींक्रोनस रूप से, सभी मानक डेटा एलिमेंट्स और वैल्यू रिप्रेज़ेंटेशन्स के पूर्ण समर्थन के साथ।</li>
    <li>बड़ी फ़ाइलों पर मेमोरी नियंत्रित करें: हर एलिमेंट लोड करें, बड़े एलिमेंट्स को तब तक defer करें जब तक उनका उपयोग न हो, या उन्हें स्किप कर केवल मेटाडेटा पढ़ें।</li>
    <li>किसी भी डेटा एलिमेंट को पढ़ें और संपादित करें, जिसमें सीक्‌वेंस और प्राइवेट टैग शामिल हैं, गैर‑ASCII टेक्स्ट के लिए कैरेक्टर सेट हैंडलिंग के साथ।</li>
    <li>DICOM PS 3.15 के गोपनीयता प्रोफ़ाइल्स के साथ DICOM फ़ाइलों को अनामित करें, UID, तिथि, डिवाइस और संस्था पहचानकर्ता तथा रोगी विशेषताओं को रखने के विकल्पों के साथ।</li>
    <li>ट्रांसफ़र सिंटैक्स के बीच ट्रांसकोड करें: JPEG, JPEG‑LS, JPEG 2000, HTJ2K, JPEG XL और RLE, सभी कोडेक .NET में लागू हैं।</li>
    <li>फ़्रेम को BGRA पिक्सल्स में रेंडर करें, मोडैलिटी LUT, VOI LUT (विंडो और लेवल) और ओवरलेज़ रेंडरर द्वारा लागू होते हुए।</li>
    <li>DICOM JSON मॉडल (PS3.18) और DICOM XML (PS3.19) में डेटासेट्स को सीरियलाइज़ और वापस परिवर्तित करें, एसींक्रोनस स्ट्रीमिंग और प्लग‑एबल बल्क डेटा लोडिंग सहित।</li>
    <li>DIMSE पर क्लाइंट और सर्वर के साथ संवाद करें: C‑ECHO, C‑STORE, C‑FIND, C‑MOVE, C‑GET, N‑services और TLS।</li>
    <li>किसी भी DICOMweb सर्वर पर QIDO‑RS, WADO‑RS, STOW‑RS, रेंडर किए गए इमेजेज, WADO‑URI और वर्कफ़्लो सर्विसेज के लिए टाइप्ड क्लाइंट के साथ स्टडीज़ खोजें, डाउनलोड और अपलोड करें।</li>
</ul>
</p>

<p>Aspose.Medical for .NET स्वतंत्र है। इसे कोई DICOM व्यूअर, कोई मेडिकल इमेजिंग सॉफ़्टवेयर या कोई नेटिव कोडेक इंस्टॉल करने की आवश्यकता नहीं है। यह हेल्थकेयर आईटी सिस्टम, PACS इंटीग्रेशन, टेलीमेडिसिन प्लेटफ़ॉर्म और उन सभी अनुप्रयोगों में फिट बैठता है जिन्हें DICOM डेटा को विश्वसनीय रूप से प्रोसेस करना आवश्यक है।</p>

DICOM फ़ाइलों को अनामित करके गोपनीयता अनुपालन सुनिश्चित करें
    </h2>
    <p>
रोगी गोपनीयता हेल्थकेयर अनुप्रयोगों में एक कड़ी आवश्यकता है। Aspose.Medical for .NET DICOM डेटा को DICOM PS 3.15 की गोपनीयता प्रोफ़ाइल्स के साथ अनामित करता है। आप रोगी पहचान जानकारी को हट या बदल सकते हैं जबकि इमेजिंग डेटा की क्लिनिकल वैल्यू बरकरार रहती है, और आप चुन सकते हैं कि प्रोफ़ाइल क्या रखती है: सुरक्षित प्राइवेट एट्रिब्यूट्स, UID, डिवाइस और संस्था पहचानकर्ता, रोगी विशेषताएँ और काल‑अनुगामी जानकारी। <a href="/medical/net/anonymization/">DICOM अनामिकरण पृष्ठ</a> में प्रोफ़ाइल विकल्पों का विस्तृत विवरण दिया गया है।
    </p>
    <div class="codeblock" id="code">
     <h3>
DICOM फ़ाइल को अनामित करें - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>

.NET C# में DICOM फ़्रेम रेंडर करें

Aspose.Medical for .NET एक DICOM फ़्रेम को 32‑bit BGRA पिक्सेल इमेज में रेंडर करता है। रेंडरर डेटासेट से फ़ोटोमैट्रिक इंटरप्रिटेशन, मोडैलिटी LUT और VOI LUT (विंडो और लेवल) लागू करता है और ओवरलेज़ को ड्रॉ करता है, ताकि परिणाम वह हो जो व्यूअर दिखाता है। पिक्सेल्स तब आपके होते हैं: उन्हें बफ़र में कॉपी करें और किसी भी इमेजिंग लाइब्रेरी को पास करके PNG, JPEG या TIFF सेव करें। लाइब्रेरी में निर्मित इमेज एन्कोडर केवल PNM है। परिवर्तन पृष्ठों में <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a> और <a href="/medical/net/dicom-to-tiff/">TIFF</a> के पूर्ण मार्ग दिखाए गए हैं।

    <div class="codeblock" id="code">

DICOM फ़्रेम रेंडर करें - C#

DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>
