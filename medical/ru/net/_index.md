<p><strong>Aspose.Medical for .NET</strong> — чистая .NET библиотека классов для работы с файлами DICOM (Digital Imaging and Communications in Medicine). Она позволяет разработчикам читать, записывать, изменять, анонимизировать, транскодировать и отображать данные медицинской визуализации, сериализовать их в DICOM JSON и DICOM XML, а также обмениваться исследованиями с другими системами через DIMSE и DICOMweb без какого-либо внешнего программного обеспечения или нативных зависимостей.</p>

<p>Библиотека полностью написана на управляемом C# и работает на .NET 10 в Windows, Linux и macOS. Нет нативных бинарных файлов и сторонних пакетов NuGet, поэтому библиотека развёртывается как единственная сборка в любое .NET приложение, от настольного инструмента до контейнера в облачной системе здравоохранения.</p>

<p><strong>Ключевые возможности:</strong>
<ul>
    <li>Чтение и запись файлов DICOM из файла, потока или канала, синхронно или асинхронно, с полной поддержкой всех стандартных элементов данных и представлений значений.</li>
    <li>Управление памятью при работе с большими файлами: загрузка всех элементов, отложенная загрузка крупных элементов до их использования или пропуск их и чтение только метаданных.</li>
    <li>Чтение и редактирование любого элемента данных, включая последовательности и частные теги, с обработкой наборов символов для текста, не являющегося ASCII.</li>
    <li>Анонимизация файлов DICOM с использованием профилей конфиденциальности DICOM PS 3.15, с опциями сохранения UID, дат, идентификаторов устройств и учреждений и характеристик пациента.</li>
    <li>Транскодирование между синтаксисами передачи: JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL и RLE, при этом каждый кодек реализован в .NET.</li>
    <li>Отображение кадров в пиксели BGRA с применением модального LUT, VOI LUT (окно и уровень) и наложений, добавленных рендерером.</li>
    <li>Сериализация наборов данных в модель DICOM JSON (PS3.18) и DICOM XML (PS3.19) и обратно, включая асинхронный стриминг и подключаемую загрузку bulk‑данных.</li>
    <li>Общение по протоколу DIMSE с клиентом и сервером: C-ECHO, C-STORE, C-FIND, C-MOVE, C-GET, N‑services и TLS.</li>
    <li>Запрос списка работ модальности, отчет MPPS и распределение задач с UPS‑RS workitems, как клиент, так и сервер.</li>
    <li>Поиск, загрузка и выгрузка исследований на любом сервере DICOMweb с типизированным клиентом для QIDO‑RS, WADO‑RS, STOW‑RS, отрисованных изображений, WADO‑URI и сервисов рабочего процесса.</li>
    <li>Создание собственного сервера DICOMweb: QIDO‑RS, WADO‑RS, STOW‑RS и сервисов рабочего процесса на ASP.NET Core или любом другом HTTP‑хосте, с вашим хранилищем за ними.</li>
</ul>
</p>

<p>Aspose.Medical for .NET является самодостаточным. Не требуется установка DICOM‑просмотрщика, медицинского визуализационного программного обеспечения или нативных кодеков. Подходит для ИТ‑систем здравоохранения, интеграции PACS, телемедицинских платформ и любых приложений, которым необходимо надёжно обрабатывать данные DICOM.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     Анонимизация файлов DICOM для соответствия требованиям конфиденциальности
    </h2>
    <p>
     Конфиденциальность пациента является обязательным требованием в медицинских приложениях. Aspose.Medical for .NET анонимизирует данные DICOM с помощью профилей конфиденциальности DICOM PS 3.15. Вы можете удалить или заменить идентифицирующую информацию о пациенте, сохраняя клиническую ценность визуализационных данных, и выбрать, какие элементы сохраняет профиль: безопасные частные атрибуты, UID, идентификаторы устройств и учреждений, характеристики пациента и продольную временную информацию. <a href="/medical/net/anonymization/">Страница анонимизации DICOM</a> подробно показывает варианты профилей.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Анонимизация файла DICOM - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Отрисовка кадров DICOM в .NET C#
    </h2>
    <p>
     Aspose.Medical for .NET преобразует кадр DICOM в 32‑битное изображение пикселей BGRA. Рендерер применяет фотометрическую интерпретацию, модальный LUT и VOI LUT (окно и уровень) из набора данных и наносит наложения, поэтому результат соответствует тому, что показывает просмотрщик. Пиксели становятся вашими: скопируйте их в буфер и передайте любой библиотеке визуализации для сохранения в PNG, JPEG или TIFF. Единственный встроенный в библиотеку кодировщик изображений — PNM. Страницы конвертации показывают полный путь для <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a> и <a href="/medical/net/dicom-to-tiff/">TIFF</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Отрисовка кадра DICOM - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Транскодирование между синтаксисами передачи
    </h2>
    <p>
     Системы визуализации и архивы требуют определённые синтаксисы передачи DICOM. Aspose.Medical for .NET транскодирует между несжатыми форматами, JPEG Baseline, JPEG Lossless, JPEG‑LS, JPEG 2000, HTJ2K (High‑Throughput JPEG 2000), JPEG XL и RLE. HTJ2K и JPEG XL — две новейшие опции в стандарте DICOM, и они реализованы в .NET как любой другой кодек. Транскодирование важно для интеграции с PACS, размера архива и совместимости между системами. См. <a href="/medical/net/dicom-transfer-syntax-conversion/">страницу конвертации синтаксиса передачи</a> и <a href="/medical/net/jpeg2000/">страницу JPEG 2000</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Транскодировать DICOM в HTJ2K - C#
     </h3>
     <pre><code class="cs">// Load existing DICOM file
DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to High-Throughput JPEG 2000, lossless
DicomFile transcoded = dicomFile.Transcode(TransferSyntax.HTJ2KLossless);

// Save the transcoded file
transcoded.Save("output.dcm");</code></pre>
    </div>

   <div class="col-lg-12">
    <h2 class="h2title">
     Сериализация DICOM в JSON и XML
    </h2>
    <p>
     Системы здравоохранения обмениваются данными через веб‑сервисы, поэтому Aspose.Medical for .NET сериализует наборы данных DICOM в модель DICOM JSON (PS3.18) и в DICOM XML (PS3.19), а также парсит их обратно в наборы данных. Сериализаторы работают со строками, потоками и каналами, синхронно и асинхронно, и последовательность наборов данных может читаться по одной без загрузки всего документа в память. Ссылки на bulk‑данные разрешаются через подключаемый загрузчик, поэтому крупные данные пикселей могут оставаться вне документа. См. страницы <a href="/medical/net/dicom-to-json/">DICOM в JSON</a> и <a href="/medical/net/dicom-to-xml/">DICOM в XML</a>.
    </p>
    <div class="codeblock" id="code">

      Сериализация DICOM в JSON и XML - C#

DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Serialize the dataset to JSON (DICOM JSON Model) and to DICOM XML

string xml = DicomXmlSerializer.Serialize(dataset);

// Parse both back into datasets
Dataset? fromJson = DicomJsonSerializer.Deserialize(json);
Dataset fromXml = DicomXmlSerializer.Deserialize(xml);</code></pre>

     Клиент и сервер DICOMweb

    <p>
     Облачные сервисы визуализации и современные архивы предоставляют DICOM через HTTP. Та же библиотека реализует серверную часть: она обрабатывает протоколы QIDO‑RS, WADO‑RS, STOW‑RS и сервисы рабочего процесса, а ваш код подключает хранилище.
