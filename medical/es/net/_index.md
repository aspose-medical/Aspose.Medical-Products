<p><strong>Aspose.Medical for .NET</strong> es una biblioteca de clases .NET pura para trabajar con archivos DICOM (Digital Imaging and Communications in Medicine). Permite a los desarrolladores leer, escribir, modificar, anonimizar, transcodificar y renderizar datos de imágenes médicas, serializarlos a DICOM JSON y DICOM XML, e intercambiar estudios con otros sistemas mediante DIMSE y DICOMweb, sin software externo ni dependencias nativas.</p>

<p>La biblioteca está escrita íntegramente en C# administrado y se ejecuta sobre .NET 10 en Windows, Linux y macOS. No existen binarios nativos ni paquetes NuGet de terceros, por lo que la biblioteca se despliega como un único ensamblado en cualquier aplicación .NET, desde una herramienta de escritorio hasta un contenedor en un sistema de salud en la nube.</p>

<p><strong>Características principales:</strong>
<ul>
    <li>Leer y escribir archivos DICOM desde un archivo, un flujo o una tubería, de forma sincrónica o asincrónica, con soporte completo para todos los elementos de datos estándar y representaciones de valores.</li>
    <li>Control de memoria en archivos grandes: cargar cada elemento, diferir los elementos grandes hasta que se utilicen, o omitirlos y leer sólo los metadatos.</li>
    <li>Leer y editar cualquier elemento de datos, incluidas secuencias y etiquetas privadas, con gestión de juego de caracteres para texto no ASCII.</li>
    <li>Anonimizar archivos DICOM con los perfiles de confidencialidad de DICOM PS 3.15, con opciones para conservar UIDs, fechas, identificadores de dispositivo e institución y características del paciente.</li>
    <li>Transcodificar entre sintaxis de transferencia: JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL y RLE, con cada códec implementado en .NET.</li>
    <li>Renderizar fotogramas a píxeles BGRA con la LUT de modalidad, la LUT VOI (ventana y nivel) y superposiciones aplicadas por el renderizador.</li>
    <li>Serializar conjuntos de datos al Modelo DICOM JSON (PS3.18) y a DICOM XML (PS3.19) y viceversa, incluyendo transmisión asíncrona y carga de datos masivos mediante complementos.</li>
    <li>Comunicar mediante DIMSE con un cliente y un servidor: C-ECHO, C-STORE, C-FIND, C-MOVE, C-GET, los servicios N y TLS.</li>
    <li>Buscar, descargar y cargar estudios en cualquier servidor DICOMweb con un cliente tipado para QIDO-RS, WADO-RS, STOW-RS, imágenes renderizadas, WADO-URI y los servicios de flujo de trabajo.</li>
</ul>
</p>

<p>Aspose.Medical for .NET es autónomo. No requiere visor DICOM, software de imágenes médicas ni códecs nativos instalados. Se adapta a sistemas de TI en salud, integración PACS, plataformas de telemedicina y cualquier aplicación que necesite procesar datos DICOM de forma fiable.</p>

   <div class="col-lg-12">
    <h2 class="h2title">
     Pure .NET Library - Zero Dependencies
    </h2>
    <p>
     Aspose.Medical for .NET está escrito completamente en C# administrado y se distribuye como un único ensamblado sin binarios nativos ni paquetes NuGet de terceros. Otras bibliotecas de imágenes médicas dependen de códecs nativos o herramientas externas; esta no lo hace. Todos los códecs de compresión de imágenes (JPEG, JPEG-LS, JPEG 2000, HTJ2K, JPEG XL, RLE) están implementados en .NET, por lo que la biblioteca se comporta de la misma manera en Windows, Linux y macOS. Esto la hace adecuada para contenedores, entornos en la nube y cualquier despliegue donde la instalación de bibliotecas nativas no sea una opción. El paquete está dirigido a .NET 10.
    </p>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Anonymize DICOM Files for Privacy Compliance
    </h2>
    <p>
     La privacidad del paciente es un requisito estricto en las aplicaciones de salud. Aspose.Medical for .NET anonimiza los datos DICOM con los perfiles de confidencialidad de DICOM PS 3.15. Puede eliminar o reemplazar la información identificativa del paciente manteniendo el valor clínico de los datos de imagen, y puede elegir qué retiene un perfil: atributos privados seguros, UIDs, identificadores de dispositivo e institución, características del paciente e información temporal longitudinal. La <a href="/medical/net/anonymization/">página de anonimización DICOM</a> muestra las opciones de perfil en detalle.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Anonymize DICOM file - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");

// Basic Application Level Confidentiality Profile of DICOM PS 3.15
ConfidentialityProfile profile = ConfidentialityProfile.CreateDefault(ConfidentialityProfileOptions.BasicProfile);
Anonymizer anonymizer = new(profile);

// Anonymize into a new file and save it
DicomFile anonymized = anonymizer.Anonymize(dicomFile);
anonymized.Save("anonymized_scan.dcm");</code></pre>
    </div>
   </div>
   <div class="col-lg-12">
    <h2 class="h2title">
     Render DICOM Frames in .NET C#
    </h2>
    <p>
     Aspose.Medical for .NET renderiza un fotograma DICOM en una imagen de píxeles BGRA de 32 bits. El renderizador aplica la interpretación fotométrica, la LUT de modalidad y la LUT VOI (ventana y nivel) del conjunto de datos y dibuja las superposiciones, de modo que el resultado coincide con lo que muestra un visor. Los píxeles son suyos: cópielos en un buffer y páselos a cualquier biblioteca de imágenes para guardarlos como PNG, JPEG o TIFF. El único codificador de imágenes integrado en la biblioteca es PNM. Las páginas de conversión muestran la ruta completa para <a href="/medical/net/dicom-to-png/">PNG</a>, <a href="/medical/net/dicom-to-jpg/">JPEG</a> y <a href="/medical/net/dicom-to-tiff/">TIFF</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Render a DICOM frame - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("chest_xray.dcm");

// Render the first frame; LUTs and overlays are applied by the renderer
using PixelImage&lt;Bgra32&gt; image = dicomFile.RenderImage(0);

// Copy the pixels out and hand them to an imaging library
Bgra32[] pixels = new Bgra32[image.Width * image.Height];
image.CopyPixelsTo(pixels);</code></pre>

    <h2 class="h2title">
     Transcode Between Transfer Syntaxes
    </h2>
    <p>
     Los sistemas de imágenes y archivos requieren sintaxis de transferencia DICOM específicas. Aspose.Medical for .NET transcodifica entre formatos sin comprimir, JPEG Baseline, JPEG Lossless, JPEG-LS, JPEG 2000, HTJ2K (High-Throughput JPEG 2000), JPEG XL y RLE. HTJ2K y JPEG XL son las dos opciones más recientes del estándar DICOM, y aquí están implementadas en .NET como cualquier otro códec. La transcodificación es importante para la integración PACS, el tamaño del archivo y la compatibilidad entre sistemas. Consulte la <a href="/medical/net/dicom-transfer-syntax-conversion/">página de conversión de sintaxis de transferencia</a> y la <a href="/medical/net/jpeg2000/">página JPEG 2000</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Transcode DICOM to HTJ2K - C#
     </h3>
     <pre><code class="cs">// Load existing DICOM file
DicomFile dicomFile = DicomFile.Open("input.dcm");

// Transcode to High-Throughput JPEG 2000, lossless
DicomFile transcoded = dicomFile.Transcode(TransferSyntax.HTJ2KLossless);

// Save the transcoded file
transcoded.Save("output.dcm");</code></pre>

    <h2 class="h2title">
     DICOM to JSON and XML Serialization
    </h2>
    <p>
     Los sistemas de salud intercambian datos a través de servicios web, por lo que Aspose.Medical for .NET serializa conjuntos de datos DICOM al Modelo DICOM JSON (PS3.18) y a DICOM XML (PS3.19), y los analiza de nuevo en conjuntos de datos. Los serializadores funcionan con cadenas, flujos y tuberías, de forma sincrónica y asíncrona, y una secuencia de conjuntos de datos puede leerse uno a uno sin mantener todo el documento en memoria. Las referencias a datos masivos se resuelven mediante un cargador complementable, de modo que los datos de píxeles grandes pueden permanecer fuera del documento. Consulte las páginas <a href="/medical/net/dicom-to-json/">DICOM a JSON</a> y <a href="/medical/net/dicom-to-xml/">DICOM a XML</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Serialize DICOM to JSON and XML - C#
     </h3>
     <pre><code class="cs">// Load the DICOM file
DicomFile dicomFile = DicomFile.Open("patient_scan.dcm");
Dataset dataset = dicomFile.Dataset;

// Serialize the dataset to JSON (DICOM JSON Model) and to DICOM XML
string json = DicomJsonSerializer.Serialize(dataset, writeIndented: true);
string xml = DicomXmlSerializer.Serialize(dataset);

// Parse both back into datasets
Dataset? fromJson = DicomJsonSerializer.Deserialize(json);
Dataset fromXml = DicomXmlSerializer.Deserialize(xml);</code></pre>

    <h2 class="h2title">
     DICOM Networking over DIMSE
    </h2>
    <p>
     Aspose.Medical for .NET se comunica directamente con otros sistemas DICOM. La biblioteca proporciona un cliente DIMSE y un servidor DIMSE para C-ECHO, C-STORE, C-FIND, C-MOVE y C-GET, junto con los N-services, negociación de asociación con contextos de presentación y roles, ventanas de operación asíncronas, negociación de identidad de usuario y TLS. Las solicitudes se encolan en una asociación y son atendidas por los manejadores que registre, de modo que un nodo store-and-forward, un proxy de consultas o un SCP de prueba son cuestión de unas pocas clases. La <a href="https://docs.aspose.com/medical/net/developer-guide/dicom-networking/">guía de redes DICOM</a> cubre la API completa.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Send a study to a PACS with C-STORE - C#
     </h3>
     <pre><code class="cs">DicomFile dicomFile = DicomFile.Open("study.dcm");

DicomNetworkClient client = DicomNetworkClient
    .CreateBuilder(new DicomNetworkClientOptions
    {
        Called = "PACS_AE",
        Calling = "CLIENT_AE",
        Connection = new DicomNetworkConnectionOptions
        {
            TargetHost = new IPEndPoint(IPAddress.Parse("192.0.2.10"), 104)
        },
        AssociationNegotiation = new AssociationNegotiationOptions()
            .WithPresentationContext(new PresentationContext
            {
                AbstractSyntax = Uid.CTImageStorage,
                Role = null,
                TransferSyntaxes = ImmutableArray.Create(TransferSyntax.ExplicitVrLittleEndian)
            })
    })
    .Build();

client.QueueRequest(new CStoreRequest(dicomFile.Dataset, TransferSyntax.ExplicitVrLittleEndian));

await client.SendAsync(CancellationToken.None);
await client.StopAsync();</code></pre>

    <h2 class="h2title">
     DICOMweb Client
    </h2>
    <p>
     Los servicios de imágenes en la nube y los archivos modernos exponen DICOM a través de HTTP. El cliente DICOMweb en Aspose.Medical for .NET envuelve cada transacción estándar en un método tipado: búsqueda QIDO-RS, recuperación WADO-RS de estudios, series, instancias, fotogramas, imágenes renderizadas y miniaturas, carga STOW-RS, WADO-URI, y los servicios de lista de trabajo, paso de procedimiento y compromiso de almacenamiento. Se ejecuta sobre su propio <code>HttpClient</code>, por lo que la autenticación y TLS permanecen donde su aplicación los configura, y los resultados llegan como los mismos conjuntos de datos y archivos con los que trabaja el resto de la biblioteca. Consulte la <a href="/medical/net/dicomweb-client/">página del cliente DICOMweb</a>.
    </p>
    <div class="codeblock" id="code">
     <h3>
      Search studies on a DICOMweb server - C#
     </h3>
     <pre><code class="cs">using HttpClient http = new HttpClient();

DicomWebClient client = new DicomWebClient(http, new DicomWebClientOptions
{
    BaseUri = new Uri("https://pacs.example.org/dicom-web/")
});

DicomWebSearchOptions search = new DicomWebSearchOptions
{
    MatchingParameters = [new DicomWebQueryParameter("PatientID", "PATIENT-001")]
};

await using DicomWebClientStream&lt;Dataset&gt; studies = await client.Studies.SearchAsync(search);

await foreach (Dataset study in studies)
    Console.WriteLine(study.GetSingleValueOrDefault(Tag.StudyInstanceUID, string.Empty));</code></pre>

   <div class="col-lg-12">
    <h2 class="h2title">
     Large DICOM Files Without Large Memory
    </h2>
    <p>
     Las imágenes de diapositiva completa, series largas y estudios multicuadro no caben cómodamente en memoria. Leer desde un flujo o una tubería y escribir de la misma manera mantiene los datos en movimiento en lugar de acumulados. La <a href="https://docs.aspose.com/medical/net/developer-guide/open-dicom-file/memory-management/">guía de gestión de memoria</a> explica los compromisos.
